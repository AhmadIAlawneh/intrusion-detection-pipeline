**A machine learning pipeline for detecting and classifying network attacks.**  
**Methods**: Preprocessing, feature selection, and multiple ML models (Logistic Regression, Random Forest, XGBoost, etc.).
**Dataset**: Contains network traffic features (e.g., `src_ip`, `dst_port`, `protocol`, etc.).
